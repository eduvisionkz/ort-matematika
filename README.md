# Өрт сөндіру ісіндегі математика

Интерактивное веб-приложение — практический продукт исследовательского проекта «Өрт сөндіру ісіндегі математика». Объект: школа имени Ш. Уәлиханова, село Тұғыл, ул. Желтоқсан, 32.

Интерфейс — на казахском языке, эта инструкция — на русском. Каждая задача показана в одном порядке: «Бастапқы деректер → Формула → Есептеу → Нәтиже», рядом с формулой всегда видна расшифровка обозначений и единиц (и на телефоне тоже).

## Разделы

| Раздел | Расчёт | Контрольные значения |
|---|---|---|
| Бөлме ауданы | S = a × b | 8 × 6 = 48 м² |
| Өрттің таралуы | r = u × t, S = π × r² (π = 3,14), только пока круг не дошёл до ближайшей стены | u = 0,3 м/мин: 1,13; 4,52; 10,17; 18,09; 28,26 м² (2…10 мин) |
| Келу уақыты | v = L / t; полоса времени 1 + 3 + 1 = 5 мин | 14 км/сағ; вызов на 1-й мин → вода на 6-й (10,17 м²), на 2-й → на 7-й (13,85 м²) |
| 2-қабаттан эвакуация | T = tдайындық + tжол + N / q | 140 с; два направления — 110 с |
| 450 / 590 адам | Tᵢ = 30 + 70 + Nᵢ/qᵢ, T = max; q = Nбағыт / (300 − 30 − 70) | 325 с, 395 с; 300/150 → 400 с (+75 с); 1,125 и 1,475 адам/с |
| Су шығыны | Q = I × S, n = ⌈Q / qствол⌉ | 28,26 м² → 2,826 л/с, 1 ствол; 48 м² → 4,8 л/с, 2 ствола |
| Су қоры | T = V / (60Q); V = Q × 60 × t | таблица 5000/6000/11 000 л × 3,5/7/14 л/с; 6300 л → −1300, −300, +4700 |
| Толықтыру | Qазаю = Qшығыс − Qкіріс | 41,67 мин; с задержкой 5 мин — 29,17 мин |
| Қызметкерлер | P = k × n + d + c | 4, 6, 7; 7 − 3 = 4 |
| Есептеу шарттары | все принятые (не измеренные) значения в одном месте | — |
| Бастапқы деректер, Фото және жоспарлар, Нәтижелер | данные, галерея, итог + CSV/JSON/печать | — |

3D-сцена показывает выбранную задачу: расчётную комнату a × b с кругом пожара (площадь круга = расчётной), приезд машины по полосе времени, эвакуацию по направлениям с очередью у выхода (1 значок = k человек, число подписано), уровень воды в цистернах, пополнение от гидранта, распределение сотрудников по задачам. Кнопки «Бастау», «Кідірту», «Қайта бастау» и скорость ×1…×120 меняют только показ, не результат. Можно зайти внутрь школы и снять крышу.

## Запуск

Нужен Node.js 18 или новее (проверено на Node 22).

```bash
npm install        # установка зависимостей (по package-lock.json)
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + сборка в папку dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
npm test           # проверка расчётных функций на контрольных значениях
```

**Почему не открывать index.html двойным щелчком.** Это приложение Vite: исходный `index.html` подключает TypeScript-модули, которые браузер без сборщика не исполняет, а собранный `dist/index.html` при открытии как `file://` блокируется политиками браузера для модулей и загрузки изображений. Для локального запуска используйте `npm run dev` или `npm run build` + `npm run preview` (либо любой статический сервер, раздающий папку `dist`).

## Размещение на Vercel через GitHub

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки (без `node_modules` и `dist` — они в `.gitignore`):
   ```bash
   git init
   git add .
   git commit -m "Өрт сөндіру ісіндегі математика"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. На vercel.com: **Add New → Project → Import** этот репозиторий.
3. Настройки (уже прописаны в `vercel.json`, Vercel подхватит их сам):
   - Framework Preset: **Vite**
   - Install Command: `npm install`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Переменные окружения **не нужны**. Нажмите **Deploy**.

Разделы переключаются через `#hash` (`/#water`, `/#results` …), поэтому обновление страницы на любом разделе работает; для надёжности в `vercel.json` добавлено перенаправление прочих путей на `index.html`.

Приложение полностью статическое: все расчёты выполняются в браузере, нет регистрации, серверной базы, Supabase/Firebase, платных API и ключей ИИ. Шрифт Noto Sans (с полной поддержкой казахских букв) и все фотографии входят в проект.

## Структура

- `src/engine/calc.ts` — все формулы (полная точность, округление только на экране до 2 знаков, десятичная запятая).
- `src/engine/compute.ts` — сводные результаты и состояние 3D-сцены в момент t (детерминированно, не зависит от скорости).
- `src/engine/sanitize.ts` — проверка ввода: отрицательные, пустые и текстовые значения заменяются; деление на ноль не выполняется (вместо этого — пояснение).
- `src/engine/engine.test.ts` — проверка на всех контрольных значениях (`npm test`).
- `src/sections/Tasks.tsx` — разделы задач; `src/sections/Info.tsx` — исходные данные, условия, итоги.
- `src/three/scene.ts` — 3D-сцена (Three.js).

## Ограничения

Значения, которые не измерялись в школе (размер комнаты, скорость распространения, времена этапов, длины путей, интенсивность подачи, расход ствола, приток при пополнении, состав задач), собраны в разделе «Есептеу шарттары». Время, на которое хватает воды, — не время тушения; время тушения не рассчитывается. Эвакуация — расчётная, не результат проведённой эвакуации.
