# Өрт сөндіру ісіндегі математика

Интерактивное веб-приложение — практический продукт исследовательского проекта «Өрт сөндіру ісіндегі математика» («Математика в пожарном деле»). Объект: школа имени Ш. Уәлиханова, село Тұғыл.

Интерфейс, подписи, формулы и отчёт — на казахском языке. Эта инструкция — на русском.

> Бұл — оқу-зерттеу моделі. Нәтижелер енгізілген деректер мен модельдік шарттарға тәуелді.
> (Это учебно-исследовательская модель, а не профессиональное заключение о пожарной безопасности.)

## Запуск

Нужен Node.js 18 или новее (проверено на Node 22).

```bash
npm install        # установка зависимостей (по package-lock.json)
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + сборка в папку dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
npm test           # проверка расчётных функций на контрольных значениях
```

**Почему не открывать index.html двойным щелчком.** Это приложение Vite: исходный `index.html` подключает TypeScript-модули, которые браузер без сборщика не исполняет, а собранный `dist/index.html` при открытии как `file://` блокируется политиками браузера для модулей и загрузки изображений. Для локального запуска используйте `npm run dev` или `npm run build` + `npm run preview` (либо любой статический сервер, раздающий папку `dist`).

## Размещение на Vercel через GitHub

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки (без `node_modules` и `dist` — они в `.gitignore`):
   ```bash
   git init
   git add .
   git commit -m "Өрт сөндіру ісіндегі математика"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. На vercel.com: **Add New → Project → Import** этот репозиторий.
3. Настройки (уже прописаны в `vercel.json`, Vercel подхватит их сам):
   - Framework Preset: **Vite**
   - Install Command: `npm install`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Переменные окружения **не нужны**. Нажмите **Deploy**.

Разделы переключаются через `#hash` (`/#water`, `/#results` …), поэтому обновление страницы на любом разделе работает; для надёжности в `vercel.json` добавлено перенаправление прочих путей на `index.html`.

Приложение полностью статическое: все расчёты выполняются в браузере, нет регистрации, серверной базы, Supabase/Firebase, платных API и ключей ИИ. Шрифт Noto Sans (с полной поддержкой казахских букв) и все фотографии входят в проект.

### Единая система вычислений и времени

Все компоненты (3D, графики, таблицы, отчёт) получают данные только из `computeAll()` и `snapshotAt()`. Состояние на момент `t` вычисляется заново из формул, а не накапливается по кадрам, поэтому:

- скорость воспроизведения не влияет на результаты;
- перемотка назад/вперёд даёт то же состояние, что и обычное воспроизведение;
- результаты не зависят от частоты кадров.

Шкалы: **t** — минуты от начала заданного сценария оповещения (t = 0); **τ** — минуты от начала подачи воды (τ = 0 соответствует t = Tначала подачи); **θ** — минуты от прибытия первого экипажа (для личного состава). При изменении параметров во время воспроизведения анимация останавливается, сцена перестраивается для текущего t, и появляется сообщение.

### Модель воды (кратко)

- Требуемый суммарный расход Q = ΣQᵢ по участвующим машинам.
- Вода машин рассматривается как общий запас (модельное условие); вода второй машины добавляется только в момент её готовности (мгновенное добавление — упрощение).
- Резерв (по умолчанию 10 %) хранится отдельно и не расходуется.
- Гидрант (если включён) даёт Qвход с заданной задержкой; запас растёт только до вместимости, избыток не накапливается; при пустом запасе фактическая подача = Qвход, запрошенный и фактический расход показываются отдельно.
- Модель событийная и точная: объём меняется линейно между событиями (готовность машины, подключение гидранта, опустошение, заполнение, конец периода).

### Формат JSON сценария

```json
{ "app": "ort-sondiru-matematika", "version": 1, "params": { "...": "см. src/engine/types.ts → Params" } }
```

При импорте неизвестные поля игнорируются, недопустимые числа заменяются значениями по умолчанию или ограничиваются допустимым диапазоном, о чём выводится предупреждение. CSV экспортируется в UTF-8 с BOM и разделителем «;» (открывается в Excel).

## Статусы данных

«Берілген мәлімет» — сведения представителя школы и оперативного плана; «Фотосуретте көрінеді» — видно на фото или планах; «Модельдік шарт» — расчётное условие работы; «Есептеу нәтижесі» — вычисленный результат. Статус показан и текстом, и значком, не только цветом.

## Проверка

`npm test` проверяет 25 контрольных групп, в том числе: 4500 л при 10 л/с → 7,5 мин; 5400 л при 14 л/с → ≈6,43 мин; задержанное пополнение → 15 мин; 700 м за 2 мин → 21 км/ч; эвакуация → 140 с; маршруты 30/30 → 110 с и 40/20 → 120 с; потребность 7 при 3 доступных → дефицит 4; 20 мин × 3 + 40 мин × 6 → 5 человеко-часов; объединённый сценарий (исчерпание при τ = 15 → t = 20, недостающие 1200 л); перерыв 1,5 мин / 900 л; производная −0,75; кусочный расход 3300 л / 9 мин; нулевая скорость или пропускная способность → прохождение невозможно.

В браузере проверены: кнопки шкалы времени, перемотка, переключение этажей, выбор помещения в 3D, изменение параметров и сообщение о недопустимом вводе, сохранение сценариев, сравнение А/Б, экспорт/импорт JSON, экспорт CSV, печать отчёта в PDF, режим без WebGL (показывается сообщение и 2D-схема, расчёты доступны).

## Ограничения и что не реализовано

- Планировка 3D построена по фотографиям планов эвакуации: порядок помещений соответствует планам, размеры приблизительные (на планах нет масштаба).
- Фото кабинетов не привязаны к номерам комнат; ручные извещатели и наружный пожарный щит показаны только в галерее (их место на плане не определено).
- Модели машин условные, без характеристик насоса и оборудования.
- Расположение гидранта и пожарной части схематичное; дорога 700 м показана без масштаба.
- Сохранение сценариев — только в браузере этого устройства (localStorage); для переноса используйте JSON.
- PDF создаётся средствами браузера («Печать → Сохранить как PDF»).
- На фото 1000303545.jpg и 1000303547.jpg видны люди — перед публичным размещением проверьте согласие.
